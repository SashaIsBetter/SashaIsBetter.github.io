01 · System

How Noetic answers.

A small model can't out-memorise frontier models, so the system spends compute where it pays: a router chooses how much to reason, tools fetch what the model doesn't know, and a verifier re-checks math and code before you see the answer.

02 · Method

VDSP: Verified Distillation with Self Practice.

Open-weight teacher models write worked solutions. Only the ones that pass a check are kept: a gold answer, unit tests, or hidden tests on an agent task. Noetic also invents its own tasks and keeps the attempts that pass. The student trains on that verified mix overnight and replaces the current model only if it scores higher on problems it has never seen.

  1. Oct 10, 2026

    VDSP: Verified Distillation with Self Practice

    VDSP is a nightly training loop for a 9B model that lives on a laptop. Free open-weight teachers and the model itself produce candidate examples; an automatic verifier keeps only the ones it can prove correct; a LoRA adapter is trained on that verified set; and the result replaces the current model only if it scores higher on problems it has never seen. This paper defines the method, shows how each part works, and reports honestly on the first three nights.

  2. Oct 8, 2026

    Training a hybrid 9B model in 16 GB

    Stock LoRA training of Qwen3.5-9B ran out of memory at the first step on a 16 GB MacBook Air. Two changes, a chunked Gated DeltaNet and a chunked vocabulary loss, brought a full 3,072-token step to 11.4 GB.
