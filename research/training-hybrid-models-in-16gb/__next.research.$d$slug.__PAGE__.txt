12:T775,<h2>The crash</h2>
<p>Noetic&#39;s base model mixes ordinary attention with Gated DeltaNet, a linear-attention layer that keeps a running state. In training mode, the MLX implementation runs that layer token by token and keeps a full 32 × 128 × 128 state for every token so it can compute gradients. That&#39;s about 2 MB per token per layer before temporaries. Our first overnight run died with <code>Insufficient Memory</code> before step one, on both Macs.</p>
<h2>Fix 1: a chunked Gated DeltaNet</h2>
<p>We wrote the chunked form of the gated delta rule in plain MLX operations: states are kept only every 64 tokens, and the work inside a chunk is a few small matrix products. It matches the reference loop&#39;s outputs and gradients.</p>
<p>One detail mattered. Inverting the 64 × 64 triangular system with a Neumann series overflowed to infinity whenever consecutive keys pointed the same way, which real text does, and training produced NaN. Block-triangular inversion is exact and stays bounded:</p>
<pre><code class="language-text">[[A, 0], [C, D]]^-1 = [[A^-1, 0], [-D^-1 C A^-1, D^-1]]
</code></pre>
<h2>Fix 2: a chunked vocabulary loss</h2>
<p>With a 248K-word vocabulary, full logits for a 3K-token example are about 3 GB in float32, plus their gradients. We project to the vocabulary 512 tokens at a time and recompute in the backward pass.</p>
